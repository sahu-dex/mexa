# Standalone reference HTML

`index.html` is based on the supplied `index mexa.html`. Its original content,
layout and buttons are retained. Tailwind CSS, Font Awesome, Poppins and AOS are
embedded in the HTML so separate CSS, font or JavaScript files are not required.
The Cloudflare-obfuscated contact address is decoded for direct file use.

The original external images, favicon and links remain unchanged and require a
network connection. This static file is separate from the PHP website.
