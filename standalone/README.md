# Standalone home page

Open `index.html` directly in a browser. Its CSS, JavaScript, local images and fonts
are embedded in that one file; no separate asset folder is needed. The Poppins font
license is included in an HTML comment.

This is a static preview of the home page, not a replacement for the live PHP site.
Existing links to other PHP pages still require the original site and server, and the
newsletter shows a demo message rather than subscribing. Existing remote Unsplash
images and media links still require internet access; they could not be embedded from
this environment. The original links are retained.
